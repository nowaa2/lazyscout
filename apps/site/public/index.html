Quick start

From zero to a QA workspace in one command.

Requires Node.js 20 or newer. LazyScout runs locally and opens the workspace in your browser.

  1. 01Run LazyScout with npx
  2. 02Create a Scout or empty Project
  3. 03Review, edit, run, and export your Test Cases
Run the latest versionNo global install required
$ npx lazyscout@latest
Install globallyUse lazyscout anywhere
$ npm install -g lazyscout
Use another workspace folderOptional

Documentation

Install and launch

Use npx for the newest public version without a permanent global installation.

npx lazyscout@latest

LazyScout starts at http://localhost:4321 and creates a local workspace before opening the UI.

Workspace files

Project data is stored on disk, not in a hosted database. Click Local Workspace in the app to open it. 

LazyScout/
├── projects/<project-id>/
│   ├── test-cases.csv
│   ├── automation/
│   ├── screenshots/
│   ├── bugs/
│   ├── reports/
│   └── logs/
└── backups/

Automation and screenshots

LazyScout generates Playwright and Cypress code. Local execution supports Playwright. A screenshot is saved only when your Playwright code explicitly calls page.screenshot().

Safety boundaries

Exploration stays within the target origin, avoids destructive actions, and uses local browser execution. Review generated Test Cases before using them in critical environments.

Troubleshooting

If no browser is available, install Playwright Chromium:

npx playwright install chromium

For the complete technical documentation, visit the repository.
